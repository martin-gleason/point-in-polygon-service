Install a map layer

This tool runs on this computer only — nothing here is on the internet. Choose a file, look at the shape it draws over the layers already installed, and then install it. Nothing is written anywhere until you press Install.

1. Choose what to install

Drag a map file here, or use the button below.

A .geojson, a .gpkg, a .zip, or a .shp together with its .dbf, .shx and .prj — select all of them at once.

or

An ArcGIS REST address — one that ends in /FeatureServer/0 or /MapServer/0, pointing at the data itself rather than at the page describing it.
How a lookup asks for this layer, as in wards_2026. Letters, numbers and underscores.
Written out in full, as in Chicago Wards (2026).
Separated by commas. These are the whole answer somebody gets back — the ward number, the district name. The columns this file actually has are listed beside the preview once you have looked at it.
Leave this empty to start with. If the file turns out to hold more than one set of areas, their names are listed in the answer and you put the one you want here.
